# 🛒 Formulário de Compra com PHP

## 📌 Sobre o projeto

Este projeto foi desenvolvido como uma atividade do curso de **Desenvolvimento de Sistemas**.

A proposta foi criar um formulário para cadastrar informações de uma compra e utilizar o **PHP** para calcular descontos de acordo com a forma de pagamento escolhida.

## 🎯 Objetivo

O objetivo do projeto é praticar a utilização de **HTML, CSS e PHP**, entendendo como o formulário envia informações para o PHP e como o código realiza os cálculos.

## 📝 Informações do formulário

O formulário permite informar:

* Nome do cliente;
* Valor da compra;
* Forma de pagamento.

As formas de pagamento são:

* 💳 Cartão de crédito — sem desconto;
* 🧾 Boleto — 8% de desconto;
* 🏦 Depósito — 10% de desconto.

Após o preenchimento, o sistema calcula o desconto e apresenta o **valor final da compra**.

## 💻 Tecnologias utilizadas

* HTML5
* CSS3
* PHP
* XAMPP
* Visual Studio Code

## ⚙️ Como executar o projeto

1. Instale o **XAMPP**.
2. Coloque a pasta do projeto dentro da pasta `htdocs`.
3. Abra o XAMPP.
4. Inicie o **Apache**.
5. Abra o navegador.
6. Acesse:

```text
http://localhost/nome-da-pasta/
```

7. Preencha o formulário e clique no botão para visualizar o resultado.

## 🧠 O que aprendi

Com essa atividade, consegui entender melhor como funciona a comunicação entre o **HTML e o PHP**. O HTML é responsável pelo formulário e pela entrada dos dados, enquanto o PHP recebe essas informações, verifica a forma de pagamento, calcula o desconto e mostra o resultado.

Também aprendi a identificar e corrigir erros no código, principalmente nos valores dos descontos e no cálculo do valor final da compra.
